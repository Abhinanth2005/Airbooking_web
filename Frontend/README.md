# AirBooking – Frontend

The frontend of AirBooking is developed using React and Vite. It provides the user interface for flight searching, booking management, user authentication, and administrative operations.

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- Axios
- React Router DOM

## Installation and Setup

Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

Install dependencies:

   ```bash
   npm install
   ```

Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in the terminal.

## Build

To create a production build:

```bash
npm run build
```

## Backend Connection

The frontend communicates with the Django REST Framework backend through REST API endpoints.

Make sure the backend server is running before using the application.
